# Intento del Proyecto: Portada HTML con estilo Liquid

## Objetivo
Construir una portada web genérica en HTML que simule un sitio moderno con estética liquid (formas orgánicas, degradados fluidos, tipografía marcada y bloques visuales dinámicos), manteniendo estructura limpia y reutilizable.

## Requisitos funcionales
- Generar una página principal única (`index.html`) con estructura semántica.
- Incluir secciones mínimas:
  - Hero con título, subtítulo y CTA.
  - Bloque de beneficios (3 tarjetas).
  - Sección de contenido destacado.
  - Footer básico con enlaces de navegación.
- Incorporar estilo visual liquid:
  - Fondos con gradientes suaves y capas fluidas.
  - Formas orgánicas (blobs) decorativas no intrusivas.
  - Composición responsive para desktop y mobile.
- Mantener contenido genérico, sin branding real ni datos sensibles.

## Requisitos técnicos
- Usar HTML5 + CSS3 puro (sin frameworks obligatorios).
- Separar estilos en `styles.css`.
- Opcional: JavaScript mínimo para efectos ligeros de entrada.
- Priorizar carga rápida y compatibilidad en navegadores modernos.

## Criterios de diseño
- Jerarquía visual clara y legible.
- Contraste suficiente para accesibilidad básica.
- Evitar saturación visual; mantener equilibrio entre decoración y contenido.
- CTA claramente visible en la primera pantalla.

## Restricciones de seguridad y calidad
- No cargar scripts de terceros innecesarios.
- No incluir credenciales, tokens ni URLs privadas.
- Evitar contenido inline inseguro cuando sea posible.
- Validar que el HTML no tenga etiquetas rotas ni estructura inválida.

## Entregables esperados
- `index.html`
- `styles.css`
- (Opcional) `script.js`
- Breve guía de ejecución local para abrir la portada.

## Criterios de aceptación
- La portada abre localmente y se visualiza correctamente en móvil y desktop.
- El estilo liquid es perceptible y coherente.
- El código es limpio, legible y fácil de extender.
